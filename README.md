# CodeBloom Website

Source for [CodeBloom](https://codebloom.org)'s public website — a nonprofit dedicated to democratizing access to tech education for underserved and underrepresented communities through coding education, transition support, and community building.

## Pages

- `index.html` — Homepage: mission overview, curriculum pillars, and ways to get involved (request a program, sponsor a course, newsletter sign-up, donate)
- `about.html` — About Us: mission and team members
- `events.html` — Events
- `yep-grant.html` — YEP! Grant award details

## Structure

Static HTML/CSS/JS site based on the [Editorial](https://html5up.net/editorial) template by HTML5 UP.

- `assets/css`, `assets/js` — template styles and scripts (jQuery-based)
- `images/` — site images and logo
- Forms and donations are embedded via Zeffy and PayPal; social links point to Facebook, Instagram, Mastodon, and Bluesky
